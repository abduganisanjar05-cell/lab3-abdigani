## Lab 3 — Modern Plain CSS

The page keeps its Lab 2 HTML and scooter-rental content and uses native CSS without a framework or preprocessor. Its layout adapts for phone, tablet, and desktop widths using Grid, Flexbox, and media queries. CSS variables keep the colors and shared design values consistent, while native CSS nesting groups related styles. `clamp()` helps headings scale smoothly, and a container query adjusts scooter cards when their available width is small.

### Why this tool

I chose Modern Plain CSS because I can build the layout without adding a framework or a compile step. Grid and Flexbox make it easier to arrange the scooter cards and keep the page readable on different screens. CSS variables let me update shared colors and sizes in one place. Nesting keeps styles for a component together, which makes the stylesheet easier to follow. The `clamp()` function lets headings grow on wider screens without becoming too large. Plain CSS does not include every shortcut or component that a framework can provide, so I still need to write the layout and components myself. Unlike Tailwind and Bootstrap, it uses my own class rules, and unlike Sass, it runs directly in the browser without preprocessing.
